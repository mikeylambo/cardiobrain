# CardioBrain — Critical Flows

First launch:
Open → Continue → Continue → Set up a session → Walk → Mix → 10 MIN → Continue to countdown → 3/2/1/GO → answer → Results → View history.
Expected path: onboarding → setup → countdown → running → results → history.

Returning user:
Open → Home → Start session → choose Activity/Mode/Duration → Continue to countdown → GO → play → Results.
Shortcut: Home → Same as last time → Countdown.

Mid-session interruption:
Start → live challenge → hide app for more than 3s → return → PAUSED → Resume → 3/2/1/GO → play → Results.
The pause interval must not count toward workout elapsed time.

Manual pause:
Start → live challenge → pause → PAUSED → Resume → 3/2/1/GO → answer → continue.

Results to next session:
Results → Go again → Countdown → GO → play → Results.
A matching Activity + Mode should produce a comparison delta.

History:
Results → View history → session appears → reload → History → same session remains.
